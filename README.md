# Regence ♟️ — шаховий клуб у браузері

Вебплатформа для гри та навчання: партії з людьми та з ботами-історичними майстрами, арени й турніри, задачі та
тренажери, школа й дебютний репертуар, розбір партій із наставником, бібліотека партій і спілкування гравців. Інтерфейс
двома мовами — англійською та українською. «Regence» — робоча назва; ім'я та домен обирає власник.

Як усе влаштовано всередині (що в яких файлах, звідки беруться дані, якими тестами перевіряється) —
**[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.

## 🚀 Що є на сайті

**Гра**

* **Партії між людьми:** лобі з викликами та автопідбір, запрошення за посиланням, рейтингові й товариські партії,
  чотири категорії контролю (куля, бліц, рапід, класика) зі своїм рейтингом Ело в кожній, передходи, реванш,
  глядачі та чат, фора, шахи Фішера. Годинник веде сервер; затримка мережі повертається гравцеві в межах квоти.
* **Арени та швейцарки між людьми:** розклад за п'ятьма конференціями світу, «останній старт» (кожна зіграна
  партія зараховується), вхід відкритий будь-якому зареєстрованому гравцеві — без поділу за силою, берсерк, нагадування
  про початок. Очки гравця йдуть і в залік його
  конференції; раз на місяць — Кубок конференцій.
* **Боти:** сім історичних майстрів XVIII–XIX століть, майстри кінця XIX та XX століття, учасники знаменитих турнірів минулого та
  вигадані архетипи; суперника можна зібрати самому з повзунків характеру. Силу ботів виміряно матчами з
  еталонами Stockfish і показано як є.
* **Клубна драбина, турніри з історичними майстрами та «Машина часу»** — знамениті турніри минулого, до
  яких гравець входить додатковим учасником.
* **Команди та сезонна ліга.**

**Навчання**

* **Задачі:** за тактичними темами (реєстр зі 125 тем), на час, задача дня, задачі з власних помилок, захист,
  матові конструкції, «Вгадай хід майстра».
* **Школа та Великий курс:** абетка, уроки, класичні партії з поясненнями, ендшпільний тренажер, звірений з
  ендшпільними таблицями, іспити рівнів, діагностика, програми тренувань, щоденна розминка, карта навичок.
* **Тренажери** зору дошки, пам'яті та рахунку, гра наосліп, навчальні міні-ігри.
* **Дебюти:** довідник зі статистикою партій і свій репертуар із повторенням за розкладом.

**Розбір і перегляд**

* **Розбір партії** рушієм і **наставник**, який пояснює ходи словами та дає підказку за ступенями.
* **Бібліотека партій**, архів чемпіонів світу, «Перегляд» партій, що тривають, імпорт власних партій з lichess і chess.com.

**Клуб**

* Підписки, сповіщення, особисті повідомлення, стрічка публікацій, спільний розбір із тренером, досягнення, модерація.
* Оформлення: дошки, набори фігур, теми-комплекти, звуки; встановлення на телефон як застосунку.

**Чесність.** Під час своєї рейтингової партії гравець не отримує від сервера оцінок і ходів рушія. Ритм ходів
аналізує античит; прапорець ставить автоматика, а рішення ухвалює модератор.

## 🛠 Технології

| Частина | Чим зроблено |
|---|---|
| Сервер | Python 3.14, FastAPI (HTTP і WebSocket), SQLAlchemy 2.0 + asyncpg, Alembic, Celery; пакети — `uv` |
| Дані | PostgreSQL 16; Redis 7.4 (стан партій, що тривають, лобі, ліміти, брокер Celery) |
| Шахи | `python-chess`, Stockfish (лише через пул процесів) |
| Клієнт | React 19, TypeScript, Vite 6, Tailwind CSS v4, `chess.js`, `recharts`, `lucide-react` |
| Перевірки | Pytest (2100+ тестів, без рушія та мережі), Ruff, mypy; Vitest (5500+ тестів), Oxlint, Playwright |

## 📦 Швидкий старт (розробка)

На ПК із Windows і Docker Desktop, з кореня проєкту:

    git clone https://github.com/TonkoshkuraMisha/regence.git regence
    cd regence
    git checkout dev
    .\start_dev.ps1

`start_dev.ps1` створює `.env` і середовище `.venv` (`uv sync`), завантажує Stockfish у `bin/`, ставить пакети клієнта,
піднімає PostgreSQL і Redis, застосовує міграції, завантажує задачі та відкриває застосунок:

* **Клієнт:** http://127.0.0.1:3000
* **Опис API (Swagger):** http://127.0.0.1:8000/docs

Ручний запуск і перевірки — `QUICKSTART.md`.
